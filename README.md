## Selected Projects

### PhishGuard

**Python | Flask | scikit-learn | Docker | GitHub Actions**

Phishing-risk analysis system that extracts more than 30 lexical and structural URL features and produces interpretable risk predictions.

The service is deliberately designed not to visit submitted URLs or perform DNS, WHOIS, or reputation lookups, keeping predictions deterministic, reproducible, and isolated from potentially malicious hosts.

Includes input validation, security headers, automated testing, model persistence, Docker packaging, CI, and graceful fallback behavior.

[View Repository](https://github.com/shreyaaaalankaaa/MachineLearning-based-Phishing)

---

### Network Threat Detection

**Python | scikit-learn | FastAPI | Streamlit | Docker**

End-to-end network threat classification system with schema validation, preprocessing, multiple-model evaluation, F1-based model selection, FastAPI inference, automated testing, Docker, and CI.

The project emphasizes reproducibility and explicitly documents the limitations of synthetic evaluation data rather than presenting it as benchmark performance.

[View Repository](https://github.com/shreyaaaalankaaa/CyberSecurity-threat-detection)

---

### CV-STGCNN Forecasting

**Python | PyTorch | Streamlit | pandas | NumPy**

End-to-end spatio-temporal deep-learning forecasting application built with PyTorch.

The system supports CSV-based prediction workflows and evaluates model performance on held-out data using MAE and RMSE, with interactive visualizations for analyzing trends, distributions, and predictions.

[View Repository](https://github.com/shreyaaaalankaaa/advanced-cv-stgcnn-forecasting-dashboard)

---

### LocalOS AI Assistant

**React | TypeScript | FastAPI | Python | Ollama | LangChain**

Local-first AI assistant integrating Qwen, DeepSeek, and Llama models through Ollama.

The system includes persistent conversation memory, voice interaction, file handling, and multiple AI interaction modes while keeping inference and user data on the user's machine.

[View Repository](https://github.com/shreyaaaalankaaa/localos-ai-assistant)
