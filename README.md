## Featured Projects

### PhishGuard
**Python · Flask · scikit-learn · Docker · GitHub Actions**

Phishing-risk analysis system that extracts 30+ lexical and structural URL features and produces interpretable risk predictions without contacting potentially malicious hosts.

[View Project](https://github.com/shreyaaaalankaaa/MachineLearning-based-Phishing)

### Network Threat Detection
**Python · scikit-learn · FastAPI · Streamlit · Docker**

End-to-end network threat classification pipeline with schema validation, preprocessing, multiple-model evaluation, F1-based model selection, API inference, automated testing, and CI.

[View Project](https://github.com/shreyaaaalankaaa/CyberSecurity-threat-detection)

### CV-STGCNN Forecasting
**Python · PyTorch · Streamlit · NumPy · pandas**

Spatio-temporal deep-learning forecasting application using CV-STGCNN with CSV-based prediction workflows, held-out evaluation using MAE and RMSE, and interactive analysis.

[View Project](https://github.com/shreyaaaalankaaa/advanced-cv-stgcnn-forecasting-dashboard)

**React · TypeScript · FastAPI · Python · Ollama · LangChain**

Local-first AI assistant integrating Qwen, DeepSeek, and Llama models with persistent memory, voice interaction, and file handling while keeping inference and user data on-device.
